# Week1-StudentPerformance-EDA
Week 1: Student Performance Analysis – EDA
Project Overview

This beginner-friendly project analyzes student exam scores in Math, Reading, and Writing.
We explore how factors such as gender, lunch type, parental education level, and test preparation course affect student performance.

The project aims to introduce basic data handling, exploratory data analysis (EDA), and visualization techniques using Python.

Dataset

Source: Students Performance in Exams – Kaggle

Features:

gender

parental level of education

lunch

test preparation course

math score

reading score

writing score

Tools & Technologies

Python (Pandas, Matplotlib, Seaborn)

Jupyter Notebook / Google Colab

GitHub for submission

Key Steps

Load the dataset using Pandas.

Explore the data using .info() and .describe().

Check for missing values.

Analyze score patterns grouped by gender, lunch, test preparation, and parental education.

Visualize trends using barplots, boxplots, histograms, and a correlation heatmap.

Summarize insights based on visual and numerical analysis.

Document the notebook with comments and Markdown explanations.

Submit project on GitHub.

Key Insights

Students who completed the test preparation course scored higher in reading and writing.

Students with standard lunch generally performed better than those with free/reduced lunch.

Gender differences exist in math scores, while females slightly outperform in reading and writing.

Higher parental education levels correlate with better student performance.

Math, reading, and writing scores are strongly correlated, showing overall academic consistency.
